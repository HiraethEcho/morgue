# 无法逃离

马特达蒙和诺顿演的《天才游戏》是一部赌狗翻身的片子，找了个争议性的叙事介质，但中心思想借达蒙的冤大头导师之口讲出

![](https://asset.877675.xyz/20260903103428231.webp)

> We can't run away from who we are.

在找工作极度焦虑的九月初，面对 AI4Math 的冲击，自身科研能力的拉胯，没钱买token的窘迫，毕业在即毫无准备的手足无措下，忧心忡忡地去五道口老乡鸡猛猛烧茄子，然后去楼下的万圣书园书店。  
这是一家神奇的书店，里面有一个哲学专区，每次都使我流连忘返，心绪跌宕起伏。
但是每次都空手而归：我实在是读不懂那些书，没有精力读那些东西，没有空间去放那些书。  
但今天走来走去，拿起了一本《神话与启蒙》，是阿多诺和霍克海姆的《启蒙辩证法》、《棱镜》的合集。
我自然可以花一些篇幅来说明我如何没读过但对他们的理论感兴趣（剧透：是因为《现代西方哲学史十五讲》），但这不重要。
重要的是，我感到一种紧张，压迫，呼吸困难。一种庞大的巨物恐惧，如房间里的大象，如身后的黑狗，如重山般的生命之轻。
无法逃避、但始终在逃避的那个巨大阴影。

人如果对自己诚实，那么必然承认有无法逃离之物。
《廊桥遗梦》中西木老爷子明白，“这样清晰明了的爱，一生只有一次”，但我们往往恐惧辨别出它。
如若承认，就面临无法逃避的抉择：放弃生活，或者放弃一切。
所以人往往装作盲人，对真实的自我视若无睹，以此来逃避自由的重负。不承认这一切，就能度过盲目而自满的一生。
这就是萨特所谓的自欺。

焦虑是来自自由的眩晕。我在那书店和那书前，正面临着这样的眩晕。
好消息是，我有丰富的面对焦虑的经验，我知道如何控制呼吸来避免呼吸性碱中毒。坏消息是，我有丰富的面对焦虑的经验，我有办法扼住我自己自由的手。

饥饿表演的艺术家清楚，那些食物不是自己喜欢的。但鲜少有人知道，自己每天都在咽下讨厌的食物；或者说，鲜少有人敢于承认自己这糟糕的品味。
《月亮与六便士》三观不正，但如果看这书是为了看三观，那宛如吃螺蛳粉嫌它臭。
每个人都有自己的大溪地，人缺少的是去那里发烂发臭但绘出壁画的勇气。

有时读书给我反复溺水般的体验。书让我探出水面呼吸，又像水草把我缠住。区别在于，生活的这里和那里，哪个是水下。
人这种下贱的东西，就是什么都会习惯的。
无论这里或那里，不要让周遭成为习以为常。

最后，我买下来那本书。我知道这是在我看到它第一眼时就决定带走它。我不知道我已经决定了要带走它。
曼哈顿博士已经知晓一切未来。曼哈顿博士依然在未来经历一切未来。
一切是实现自身的寓言，命运是沉睡的奴隶，只等人自己把它唤醒，从滚石中雕刻出自身的石像。
