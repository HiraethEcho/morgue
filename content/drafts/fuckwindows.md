# Windows 真难用吧

## 臃肿

重置电脑之后：C盘用了70G，啥也没干内存7G. 太变态了

虽说70G里有页面文件和虚拟内存，大概12.5G + 5G。但是 WinSxS, WindowsApps 是在干嘛？太恶心了呀

反复重置，但是我之前卸载的软件，为什么断网重置后又会出现呢？就一定要留着那狗屎安装包吗？

清理和卸载后，C盘占用拉低到 45G。接着在微PE里用分区助手压缩C盘，然后再重置反复几次。
C盘从 300G 的初始大小缩减到 64G，windows明明能干人事，这次重置完只有 58.7 G占用，还包括 12.5+5 的虚拟占用

wiztree还是好用

这个新的文件浏览器，和设置中心，真的一坨啊
在右键属性、 win + I 设置中心、控制面板间反复横跳，真的智障一样
在 `此电脑` 右键属性，会跳到设置中心；在那里选高级系统设置，又跳回常规的右键属性里
想要调盒盖行为，在控制中心和设置里都有，好烦
输入法相关设置，在语言、输入法、键盘到处都有，恶心
右键展开更多选项，太变态了，换 UI 不说，多出来的选项是 tm 一个不能用的粘贴，服了

还有一堆滑入滑出的

这个 window power automate 到底是干嘛的，好恶心啊
还有 onedrive, onenote, edge, 真该死吧

onenote和office绑定是何意味啊？卸载office推荐安装一个卸载工具？

这个windowsapp是最恶心的，什么叫 TustedInstaller 这个角色，比系统管理员权限还高？
卸载软件仅仅是对此账户不可见，实际上还有安装包，要命令行用 `Remove-Package -AllUsers` 才行，太恶心了
安装位置修改，要在 存储新应用 里改，这对吗？
你搞UWP给我搞好了呀
