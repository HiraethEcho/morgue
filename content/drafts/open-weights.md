# 免费、开源和自由

最近和朋友聊天，起因是看到一个新闻，claude在desktop版中塞了libreoffice，以及之前codex那边塞了git等
感叹开源软件被这么用，好惨

接着聊到开放权重模型，算不算开源。
先说我的结论：形式上看似开源，实质上并不免费，难以成为自由

权重和汇编是类似的

在大众层面上，人们往往把开源和免费联系起来，但这两个很不一样

开源软件指源代码开放，从朴素逻辑上看有了代码就可以免费使用；
免费软件仅仅指不收费，但在资本主义世界里有一句老话，免费的就是最贵的

obsidian 是免费软件，但并不开源。
linux是开源系统，但Redhat是商业公司，提供付费服务

alist被收购，社区代码被卖给公司，服务端企图获取用户信息

windows系统往往被称为“赠送”内容和电脑绑定，然后你就获得了 无法关闭的更新、无法删除的edge、占你内存的狗屎后台程序

对Linus 来说，开源是写出更好代码的方式

顺便一提，linux本人并不排斥 ai，
。他很早就不怎么自己写代码了，想要什么往邮件列表一发，就有智能工人带着 pull request 过来了。
毕竟谁能拒绝把自己的代码合并进内核呢？
他排斥垃圾工作流写的狗屎。就像他讨厌铺天盖地的毫无意义的ai找出来的内核漏洞. 以及之前他对 rust 驱动争端的插手：你可以自己不写rust，但不能阻止其他人

微软表示学到了，并且把vscode扔出来白嫖社区力量
