# 写作风格及博客结构

## 写作内容风格

### 批判（Critique）

**基调**：悲观但不消极，保持愤怒、保持批判。直接有力，自嘲自贬是常态。

**结构**：个人入口 → 现象描述 → 理论抽象 → 多角反思 → 开放式收尾。

**格式习惯**：

- 用 `[^n]` 脚注

**该类型特有禁忌**：

- 避免空洞漂亮话（"让我们一起……"）
- 避免 AI 典型句式（"值得注意的是"、"毋庸置疑"）
- 避免过于规整的 bullet point

**AI 协作边界**：校对病句、错别字可交 AI。文风/语气/自嘲/粗口分寸/批判洞见必须人工主导。

### 文化产品评论（Kulturprodukte）

**基调**：以某部电影/剧/书/动漫为锚点，进行严肃分析而非简单评价。语气可以强烈，不保守或假装中立，观点鲜明。

**结构**：

1. **作品信息交代** — 何时看、什么背景、个人与作品的关系
2. **整体评价** — 先给出总判断（好活/烂了/复杂）
3. **多向度分析** — 分角度拆解（叙事/视听/主题/角色等）
4. **理论/对比** — 借用理论框架或横向对比其他作品
5. **回归作品定位** — 在文化坐标中判断其价值

**格式习惯**：

- 作品名用书名号 `《》`
- 嵌入截图/meme 辅助说明
- 多段落分析，每段聚焦一个角度

**该类型特有禁忌**：

- 避免仅写"好看/不好看"的简单评价
- 避免剧透而不预警
- 避免只分析内容而不分析形式（视听/叙事技术）
- 避免过度拔高（每部电影不一定都要"颠覆性"）

**AI 协作边界**：检查事实性错误（演员/导演/年份）、补充背景知识可交 AI；审美判断、跨作品比较、理论联系必须人工主导。

### 个人内省（Introspection）

**基调**：坦诚、脆弱，承认无知和困惑。常出现"我不知道怎么办"、"这不好，但我不知道怎么办"。语气反省而非辩解。

**结构**：

1. **触发事件** — 某次交流/经历引发反思
2. **问题描述** — 具体化自己的缺陷/矛盾
3. **心理分析** — 尝试（用理论或直觉）解剖自己
4. **提供思考材料** — 放上引文/案例/问题，不一定有答案
5. **开放收束** — 承认仍无解，但记录过程

**核心句式**：

- "被指出……，我逐渐有所自知"
- "我的看法是……然而……"
- "也许可以称之为某种狡辩"
- "这不好，但我不知道怎么办"

**格式习惯**：

- 嵌入外部视频/引文作为思考材料
- 与已有博客交叉引用
- 有时用 `>` 引用他人观点/对话

**该类型特有禁忌**：

- 避免自我辩护或甩锅
- 避免下结论（"我改好了"——实际没改好）
- 避免过于抽象（要落回具体的行为/事件）
- 避免从内省滑向说教

### 哲学随笔（Philosophical Essay）

**基调**：从抽象概念出发进行形而上思辨，不急于批判，而是追问。语气冷静但不冷漠，承认自己的知识有限。

**结构**：

1. **引出问题** — 从日常现象/经典悖论/阅读触发
2. **概念分析** — 拆解核心概念的含义
3. **多视角考察** — 列举不同哲学家的回答
4. **自己的立场** — 在梳理后给出个人的倾向
5. **回到生活** — 抽象思辨最终指向"那该如何生活"

**核心句式**：

- "如果……那么……"
- "在……意义上，……"
- "这里借用 X 的概念……"
- "严格来说……然而日常语境下……"

**格式习惯**：

- 引用哲学家原文（`>` blockquote）
- 用 `[^n]` 脚注做延伸说明
- 有时使用 mathjax 数学公式辅助表达

**该类型特有禁忌**：

- 避免堆砌术语而无论证
- 避免假装读懂了没读过的书
- 避免过度引用（变成读书笔记而非哲学随笔）
- 避免脱离生活落地

**AI 协作边界**：检查逻辑一致性、补充哲学家的基本观点可交 AI；核心思辨、个人立场、论证组织必须人工主导。

### 漫谈（Mumble）

**基调**：自由联想，无固定结构，想到哪写到哪。语气最"裸"——不急于论证什么，只是思维流动的记录。可以散，但不能空。

**结构**：

- 没有固定结构，但通常有一个**触发点**（一件小事/一个念头）
- 内容呈**放射状**而非线性的
- 结尾可以突然收住，不需要结论

**核心句式**：

- "随便想到什么写什么"
- "这是一些零碎的想法"
- "话又说回来……"
- "另一个想法是……"

**格式习惯**：

- 常用短段落（2-5 行一段）
- 链接少，更接近独白
- 标题可以很随意甚至不加标题直接写

**该类型特有禁忌**：

- 避免假装随性实际精心设计
- 避免纯情绪宣泄而无内容
- 避免过于个人化到外人无法理解
- 避免"写着写着忘了我本来想写啥"（可以用括号备注）

**AI 协作边界**：可做的事很少——语病校对尚可，但任何风格干预都会破坏漫谈的自然感。AI 只能做最轻量的病句检查。

### Weblog（网络日志）

**基调**：混合了社交实验、公共舆论观察和自我反思。作者既是参与者又是观察者。语气可以尖锐、讽刺、自嘲。

**结构**（常见模式）：

1. **起因** — 在公众号/知乎/小红书做了什么（发了一篇文章/一个评论）
2. **过程记录** — 说了什么、发生了什么反应
3. **反应分析** — 分析读者/留言的群体心理
4. **自我反思** — 自己做得对不对、收获了什么
5. **更广泛的讨论** — 扩展到公共言论、媒介理论等

**核心句式**：

- "没想到的是……"
- "我怀疑……"
- "对此行为的批评我都接受"
- "作为社会实验……"
- "阅读了吗？如读。"

**格式习惯**：

- 使用截图展示留言区/公众号后台
- 引用/复述留言区内容
- 标注哪些内容是从公众号版本到完整版本的差异
- 用 `update:` 标注事态发展
- 直接分析"钓鱼"/"反串"行为的利弊

**该类型特有禁忌**：

- 避免单纯的宣泄而缺少分析
- 避免过度解释自己的"钓鱼"动机
- 避免沉迷于"胜利感"——weblog 不是来赢的
- 避免成为纯情绪垃圾桶

**AI 协作边界**：帮助组织时间线和事态发展可交 AI；舆论分析、自我反思、讽刺分寸必须人工主导。

## 内容位置参考

用于判断文章应放入哪个目录。目录判断需要结合内容来源、成熟度、写作类型和 frontmatter 状态。

### forest/

原始素材区，保存未精炼、未发布或外部来源内容。

| 路径              | 用途          | 适合内容                               |
| ----------------- | ------------- | -------------------------------------- |
| `forest/clip/`    | 外部文章剪报  | 网页保存、资料备份、外部文章原文       |
| `forest/excerpt/` | 书籍/文章摘录 | 引文、摘抄、阅读材料                   |
| `forest/morgue/`  | 草稿坟场      | idea、outline、draft、未成形文本       |
| `forest/weblog/`  | 网络日志目录  | 社交平台记录、评论区观察、公共舆论实验 |

### glade/

表达作品区，保存经过整理、可被当作博客正文阅读的文本。

| 路径           | 用途             | 适合内容                                                                        |
| -------------- | ---------------- | ------------------------------------------------------------------------------- |
| `glade/essay/` | 长文、评论、分析 | critique、kulturprodukte、philosophical essay、完整论证；以自己的观点和论证为主 |
| `glade/memo/`  | 短文、随笔、备忘 | mumble、轻量观点、阶段性想法；以自己的感受、判断和阶段性想法为主                |

### garden/

知识库，存放学习吸收后的整理材料。内容来源通常是书、文章、课程、外部摘抄或概念材料，重点是把学来的东西整理清楚。

| 路径                | 用途     | 适合内容                                                                         |
| ------------------- | -------- | -------------------------------------------------------------------------------- |
| `garden/note/`      | 学习笔记 | 学习后的总结，可用 critique / kulturprodukte 等 category，但文章形态仍以笔记为主 |
| `garden/rudiments/` | 知识原料 | 概念、定义、理论碎片、可复用知识点、教程指南                                     |

### diary/

私人时间线。

| 路径     | 用途 | 适合内容                            |
| -------- | ---- | ----------------------------------- |
| `diary/` | 日记 | 日常记录、晨间/晚间反思、私人时间线 |

### 目录判断优先级

1. 外部原文、摘录、知识素材优先放 `forest/`
2. 未成形 idea/outline/draft 优先放 `forest/morgue/`
3. 网络事件记录、评论区观察、社交平台实验优先放 `forest/weblog/`
4. 可发布表达作品按形态放 `glade/essay/`、`glade/memo/`
5. 知识学习类整理按形态放 `garden/note/` 或 `garden/rudiments/`
6. 私人日常记录放 `diary/`
